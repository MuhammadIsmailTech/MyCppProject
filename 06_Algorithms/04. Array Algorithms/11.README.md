# Introduction

Arrays are one of the most fundamental data structures in Computer Science. An array stores multiple elements of the same data type in **contiguous memory locations**, allowing efficient access using an index.

Array algorithms involve performing operations such as searching, finding maximum and minimum values, reversing elements, copying arrays, and calculating sums or averages.

These algorithms are the foundation for learning advanced Data Structures and Algorithms (DSA).

---

# What is an Array?

An array is a collection of elements stored in consecutive memory locations.

Example:

```text
Index

0   1   2   3   4

↓

Array

10  20  30  40  50
```

Each element can be accessed using its index.

Example

```cpp
arr[0] = 10
arr[3] = 40
```

---

# Advantages of Arrays

- Fast access using index
- Easy to traverse
- Simple implementation
- Stores multiple values of the same data type
- Efficient memory usage

---

# Disadvantages of Arrays

- Fixed size
- Insertion is expensive
- Deletion is expensive
- Cannot grow dynamically (Static Arrays)

# 1. Find Maximum Element

### Idea

Traverse the array and keep updating the maximum value.

Example

```text
Array

25 10 45 78 12 90 34

↓

Maximum = 90
```

Time Complexity

```text
O(n)
```

Space Complexity

```text
O(1)
```

# 6. Reverse Array

### Idea

Swap the first and last elements until reaching the middle.

Example

```text
Original

10 20 30 40 50

↓

Reversed

50 40 30 20 10
```

Time Complexity

```text
O(n)
```

Space Complexity

```text
O(1)
```

---

# 7. Copy One Array to Another

### Idea

Copy every element from the source array into another array.

Example

```text
Source

↓

Destination

10 20 30
```

Time Complexity

```text
O(n)
```

Space Complexity

```text
O(n)
```

---

# 8. Print Array in Reverse Order

### Idea

Print elements from the last index to the first without modifying the original array.

Example

```text
Original

10 20 30 40 50

↓

Output

50 40 30 20 10
```

Time Complexity

```text
O(n)
```

Space Complexity

```text
O(1)
```

---

# 9. Find Largest and Smallest Element

```text
Array

Largest = 90

Smallest = 10
```

Time Complexity

```text
O(n)
```

Space Complexity

```text

```

---

# 10. Search an Element (Linear Search)

### Idea

Compare the target value with each element until it is found.

Example

```text
Array

10 20 30 40 50

↓

Search = 40

↓

Found at Index 3
```

Time Complexity

| Case | Complexity |
|------|------------|
| Best | O(1) |
| Average | O(n) |
| Worst | O(n) |

Space Complexity

```text
O(1)
```
